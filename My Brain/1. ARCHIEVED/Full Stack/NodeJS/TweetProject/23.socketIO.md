# WebSocket

- là 1 giao thức giúp client và server có thể giao tiếp với nhau 2 chiều
- nói cách khác, nó giúp server có thể gửi thông tin đến client mà không cần client phải request
- ví dụ như mấy game online, chat, v.v...
- nói chung là những ứng dụng cần realtime

## websocket

- là 1 thư viện hổ trợ viết code và sử dụng websocket một cách đơn giản và hiệu quả
- ngoài ra hỗ trợ HTTP fallback cho các trình duyệt không hổ trợ websocket, thông qua công nghệ HTTP long-polling

## cài đặt

- tham khảo cài đặt ở [đây](https://socket.io/docs/v4/server-installation/)

- **ở bên phía `server`**

  - ta cài đặt `socket.io`

    ```ts
    npm install socket.io
    npm install --save-optional bufferutil utf-8-validate
    ```

  - trong file `index.ts`

    ```ts
    import { Server } from 'socket.io'
    import { createServer } from 'http'
    ...
    const app = express()
    const httpServer = createServer(app) // thêm dòng này

    ...
    const io = new Server(httpServer, {
        //option của server
        cors: {
            origin: 'http://localhost:3000'//cấp quyền truy cập cho client
        }
    })
    //client kết nối với server thì sẽ hiển thị ra dòng này, cho server biết
    //trong callback này socket là đại diện cho 1 client đang sử dụng
    io.on('connection', (socket) => {
      console.log(`new client has id: ${socket.id} is connected`)
      socket.on('disconnect', () => {
        console.log(`client has id: ${socket.id} is disconnected`)
      })
    })
    //thay từ app thành httpServer.listen
    httpServer.listen(port, () => {
        console.log(`server đang chạy trên post ${port}`)
    })

    ```

    - chạy server `npm run dev`

- **ở bên phía `client`**

  - ta cài đặt `socket.io-client`

    ```ts
    npm install socket.io-client
    ```

  - trong file `.env` thêm

    ```ts
    VITE_API_URL = 'http://localhost:4000' //port của server
    ```

  - trong `src` tạo file `Chat.jsx`

    ```jsx
    import { useEffect } from 'react'
    import io from 'socket.io-client'
    //ai vào trang chat thì sẽ kết nối với socket
    export default function Chat() {
      useEffect(() => {
        const socket = io(import.meta.env.VITE_API_URL) //kết nối server
        //khi thành công thì
        socket.on('connect', () => {
          console.log('connected with id = ', socket.id)
        })
        //khi bị mất kết nối thì
        socket.on('disconnect', () => {
          console.log('disconnect with id = ', socket.id)
        })
        //clean up function : khi component bị unmount thì sẽ disconnect| phần này cho chắc vậy thôi chứ thật ra k có vẫn tự disconnect
        return () => {
          socket.disconnect()
        }
      }, [])
      return <div>Chat</div>
    }
    ```

  - trong `route.jsx` thêm

    ```jsx
    const router = createBrowserRouter([
      ...{
        path: 'chat',
        element: <Chat />
      }
    ])
    ```

      ```ts
      import databaseService from './database.services'

      class ConversationServices {
        async getConversations({
          sender_id,
          receiver_id,
          limit,
          page
        }: {
          sender_id: string
          receiver_id: string
          limit: number
          page: number
        }) {
          //tạo filer để lấy các cuộc trò truyện của mình và người gữi
          const math = {
            $or: [
              {
                sender_id: new ObjectId(sender_id),
                receiver_id: new ObjectId(receiver_id)
              },
              {
                sender_id: new ObjectId(receiver_id),
                receiver_id: new ObjectId(sender_id)
              }
            ]
          }
          //lấy các cuộc trò truyện của mình và người gữi, đồng thời phân trang
          const conversations = await databaseService.conversations
            .find(math)
            .sort({ created_at: -1 })
            .skip(limit * (page - 1))
            .limit(limit)
            .toArray()
          //lấy tổng số tin nhắn: dùng filter giống ở trên
          const total = await databaseService.conversations.countDocuments(math)
          return {
            conversations,
            total: total
          }
        }
      }
      ```

# middleware server instance

- ta có thể tham khảo tài liệu tại [đây](https://socket.io/docs/v4/middlewares/)
- cấu trúc của nó dạng

  ```ts
  io.use((socket, next) => {
    //middleware
    next()
  })
  ```

- rất là giống với `express middleware`, và nó sẽ chạy trước khi kết nối socket
- vậy thì nghĩa là socket sẽ có 3 trạng thái

  - `middleware` -> `connect` (lắng nghe các sự kiện truyền lên ) -> `disconnect`

- giờ ta sẽ tạo thử 1 middleware kiểm tra xem client có truyền lên socket io `access_token` hay không ? giống như `accessTokenValidator` mà ta đã làm

  - **bên phía client**
    - ta sẽ không truyền vào `user._id` khi kết nối nữa, mà thay bằng `access_token`, ta vào file `index.ts`
      ```jsx
      useEffect(() => {
        socket.auth = {
          Authorization: `Bearer ${localStorage.getItem("accessToken")}`,

      ```
  - **bên phía server**

    - vì ta sẽ phải kiểm tra `access_token` như `accessTokenValidator` nên ta sẽ tách thành hàm để tái sử dụng
      ta sẽ lưu hàm này vào file `common.ts`

      ```ts
      export const verifyAccessToken = async (access_token: string, req?: Request) => {
        //lấy từ đoạn kiểm tra access_token có tồn tại không
        if (!access_token) {
          throw new ErrorWithStatus({
            message: USERS_MESSAGES.ACCESS_TOKEN_IS_REQUIRED,
            status: HTTP_STATUS.UNAUTHORIZED
          })
        }
        try {
          const decoded_authorization = await verifyToken({
            token: access_token,
            secretOrPublicKey: process.env.JWT_SECRET_ACCESS_TOKEN as string
          })
          //vì dùng trong express middleware thì có req, còn bên socket middleware thì không có
          //nên nó xem là optional thôi, nếu có truyền vào req thì lưu decoded_authorization vào req
          if (req) {
            ;(req as Request).decoded_authorization = decoded_authorization
          }
          return req ? true : decoded_authorization
        } catch (error) {
          throw new ErrorWithStatus({
            message: capitalize((error as JsonWebTokenError).message),
            status: HTTP_STATUS.UNAUTHORIZED
          })
        }
      }
      ```

    - vậy thì `accessTokenValidator` sẽ thành

      ```ts
      export const accessTokenValidator = validate(
        checkSchema(
          {
            Authorization: {
              custom: {
                //value là giá trị của Authorization, req là req của client gữi lên server
                options: async (value: string, { req }) => {
                  const access_token = (value || '').split(' ')[1]
                  return await verifyAccessToken(access_token, req as Request)
                }

            }
          },
          ['headers']

      )
      ```

    - ta vào `index.ts` thêm `socket middleware` trước `io.on('connect')`

      ```ts

        const access_token = Authorization?.split(' ')[1]

          const { verify } = decoded_authorization as TokenPayload

          if (verify !== UserVerifyStatus.Verified) {
            throw new ErrorWithStatus({
              message: USERS_MESSAGES.USER_NOT_VERIFIED,
              status: HTTP_STATUS.FORBIDDEN
            })
          }
          //lưu user_id vào socket.handshake.auth
          socket.handshake.auth.decoded_authorization = decoded_authorization as TokenPayload
          next()
        } catch (error) {
          //nếu chỉ next error thôi thì sẽ lỗi đấy vì nó quy định lỗi này phải cấu trúc như dưới đây
          next({
            message: 'Unauthorized',
            name: 'UnauthorizedError',
            data: error
          })
        }
      })
      ```

# middleware socket

- ta có thể tham khảo ở đây [đây](https://socket.io/docs/v4/server-socket-intance/)
- ở phần trước ta có tạo ra middleware nhưng nó chỉ chạy lần đầu khi ta kết nối thôi,
  giờ ta muốn mỗi lần nhắn tin thì nó sẽ chạy lại xem thử người dùng còn hạn access_token không, nếu hết hạn rồi thì k cho gữi, ép phải đăng nhập

  - **bên phía server**
    trong socket.io ta có 2 dạng middleware là server instance (io.use) và socket instance (socket.use)

    - server instance: chạy trước khi kết nối socket
    - socket instance: chạy trước khi nhận sự kiện từ client(chạy trong io.on('connection'))
    - syntax

      ```ts
      socket.use(([event, ...args], next) => {
        //middleware
        next()
      })
      ```

    - ta vào `index.ts`

    ```ts
    io.on('connection', (socket) => {
      console.log(`new client has id: ${socket.id} is connected`)
      const { user_id } = socket.handshake.auth.decoded_authorization as TokenPayload
      users[user_id] = {
        socket_id: socket.id
      }
      //socket middleware
      socket.use((packet, next) => {
        console.log("ối dồi ôi");

        next(new Error('ahuhu'))
      })
      //error handler của socket
      socket.on('error', (err) => {
        console.log(err)
      })
      socket.on('send_message', async (data) => {
    ...
    })
    ```

    - kết quả thu được khi client kết nối và nhắn tin, vậy nó chỉ chạy khi có sự kiện, còn lúc kết nối sẽ k chạy
      ![[image-433.png]]
    - giờ ta sẽ bắt đầu làm

      - bên `server middleware` ta phải truyền access_token xuống cho `socket middleware` để nó kiểm tra

      ```ts
        //middleware của socket.io
        io.use(async (socket, next) => {
            ...
            socket.handshake.auth.decoded_authorization = decoded_authorization as TokenPayload
            socket.handshake.auth.access_token = access_token // lưu thêm access_token
            next()
          } catch (error) {
            ...
        })


      io.on('connection', (socket) => {
        console.log(`new client has id: ${socket.id} is connected`)
        const { user_id } = socket.handshake.auth.decoded_authorization as TokenPayload
        users[user_id] = {
          socket_id: socket.id
        }
        //socket middleware
        socket.use(async (packet, next) => {
          const { access_token } = socket.handshake.auth
          try {
            await verifyAccessToken(access_token)
            next()
          } catch (err) {
            //next này nhận vào Error mặc định
            next(new Error('Unauthorized'))
          }
        })
        //error handler của socket
        socket.on('error', (err) => {
          //nếu nhận đc lỗi Unauthorized thì disconnect socket
          if (err.message === 'Unauthorized') {
            socket.disconnect()
          }
        })
      ```

  - **bên phía client**
    - ta bắt sự kiện đã `disconnect` để thông báo cho người dùng
      ```jsx
      useEffect(() => {
        ...
        socket.on('disconnect', (reason) => {
          console.log(reason)
        })

          socket.disconnect()
        }
      }, [])
      ```
