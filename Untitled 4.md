| Loại tấn công           | Công dụng / Ý nghĩa chính                                                                                                   | Cách hoạt động (payload ví dụ)                                                                    |
| ----------------------- | --------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------- |
| **Boolean-based blind** | Khai thác bằng cách gửi truy vấn có điều kiện đúng hoặc sai (true/false). Qua phản hồi đúng/sai, hacker đoán được dữ liệu.  | Ví dụ: `cat=1 AND 5284=5284` (luôn đúng) – Nếu trang trả về dữ liệu bình thường → tồn tại lỗ hổng |
| **Error-based**         | Tận dụng các thông báo lỗi từ database trả về để lấy dữ liệu nhạy cảm (ví dụ tên bảng, cột).                                | Ví dụ: `cat=1 AND GTID_SUBSET(CONCAT(...))` gây lỗi và lộ dữ liệu qua lỗi                         |
| **Time-based blind**    | Dựa vào độ trễ phản hồi từ server, ví dụ dùng câu lệnh `SLEEP(n)`. Nếu server chậm lại khi có payload, chứng tỏ có lỗ hổng. | Ví dụ: `cat=1 AND (SELECT SLEEP(5))` → server chậm 5 giây nếu bị lỗi                              |
| **UNION query**         | Kết hợp nhiều truy vấn SELECT lại với nhau để hiển thị dữ liệu từ các bảng khác, vượt qua giới hạn truy vấn ban đầu.        | Ví dụ: `cat=1 UNION ALL SELECT NULL,NULL,...,CONCAT(...)` để chèn và hiển thị dữ liệu             |
